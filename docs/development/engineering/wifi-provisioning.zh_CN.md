# 通过设备内网页配网连接 Wi-Fi

固件最多在 NVS 中保存六个 Wi-Fi 网络，并在开机时连接当前选中网络。新增网络
直接在设备上完成：进入设置页，选择「Wi-Fi 网络」，再选择「手机网页配网」。
设备临时开启热点并提供 HTTP 配置页，手机无需配套小程序，也不使用蓝牙。

## 配网流程

1. 屏幕显示热点名称（`AI-Passport-XXXX`，取自 SoftAP MAC）和开机时随机生成的
   8 位 WPA2 密码。密码只在设备屏幕上显示，因为配网页会保存服务器 API Token。
2. 手机连接该热点，打开 `http://192.168.4.1`。
3. 页面顺序为 **服务器 → 显示设置 → Wi-Fi**。服务器条目包含中转地址和
   `X-Api-Token`；显示设置包含亮度、刷新间隔和熄屏时间。
4. 最后一张卡片是「连接并退出配网」。提交后保存配置、显示带新网络名称的说明，
   关闭配网热点，切回 STA 模式并连接。
5. 若设备已经联网，配网不会另开热点，而是直接使用设备局域网地址提供服务；
   屏幕的「设置 → Wi-Fi 网络」会显示该地址。

可以跳过 Wi-Fi 卡片。「暂不配网，直接退出」会关闭配网并返回设置页，不改变
当前选中的网络。

## 代码入口

- `main/app_portal.c`：HTTP 服务生命周期、请求处理、配置应用，以及先关热点
  再重连的 `then_exit` 请求。
- `main/portal.html`：内嵌页面及其 JavaScript，在 `main/CMakeLists.txt` 中以
  `EMBED_FILES` 注册。
- `main/app_wifi.c`：保存网络状态机、扫描、SoftAP 启停、省电策略和重连逻辑。
- `main/app_config.c`：NVS 配置与 UI 任务共享的快照锁。
- `main/main.c`：`exit_portal()` 决定关闭顺序——先返回本地界面，再停止
  `httpd`，退出 SoftAP 模式，最后调用 `app_wifi_note_config_changed()`。

## HTTP 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/` | 内嵌配置页面 |
| `GET` | `/api/config` | 当前服务器、显示设置和已保存网络 |
| `GET` | `/api/scan` | 2.4 GHz 扫描结果，按信号从强到弱 |
| `POST` | `/api/wifi` | 添加、激活或删除已保存网络 |
| `POST` | `/api/server` | 添加、编辑或删除服务器 |
| `POST` | `/api/settings` | 亮度、刷新间隔和熄屏时间 |
| `POST` | `/api/test` | 从设备侧测试中转地址和 Token |
| `POST` | `/api/exit` | 关闭配网且不改变当前网络 |

`httpd` 任务使用 20 KB 栈，因为 `/api/test` 会在该任务内同步发起 TLS 请求，
配置快照也占用栈空间。启动配网前会先取消在途的监控请求，否则 TLS 握手缓冲和
HTTP 服务会争抢同一块内部 RAM。

## 接入规则

- 配网属于应用层，不放入 `components/bsp`；BSP 不提供网络接口。
- 禁止记录或提交 Wi-Fi 密码与服务器 Token。热点密码每次开机重新生成，且只显示
  在设备屏幕上。
- 页面在本地链路上使用明文 HTTP，因为设备没有 `192.168.4.1` 的证书；这不是
  生产级授权设计。热点开启期间，热点密码是唯一的访问控制。
- 配置损坏时不要通过擦除 NVS 掩盖问题，应校验并报告错误。

## 验收

运行[验证门禁](build-and-test.zh_CN.md)，再遵循
[真机测试交接流程](../ai-guide.zh_CN.md#主动询问真机测试)。实机检查：

- 屏幕显示的热点名称和密码与手机搜索到的一致。
- `http://192.168.4.1` 可以打开，服务器、显示、Wi-Fi 三张卡片顺序正确。
- 保存服务器和显示设置后连接 Wi-Fi，配网关闭并直接联网，无需再手动点一次连接。
- 热点关闭后，「设置 → Wi-Fi 网络」显示新 IP。
- 密码错误时设备保持重试，不得显示成功。
- 不填 Wi-Fi 直接退出配网会返回设置页，并保留原选中网络。
- 重启、息屏/唤醒、反复进入退出配网不会重复创建 `httpd` 任务或泄漏堆。

编译成功不能证明网页兼容性或实机联网正常；未执行的检查列入 `Unverified`。
